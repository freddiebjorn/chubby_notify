# Bidrag

Fejl og ønsker oprettes som [issue](../../issues). Til almindelige spørgsmål er der Chubby Development-serveren på Discord: <https://discord.gg/vwe8b8fnRm>.

Vil du rette noget selv, så lav en pull request.

- Hold ændringen lille og til ét formål
- Beskriv i pull requesten, hvad der ændres, og hvordan du har prøvet det
- Ændres opførslen eller indstillingerne, så ret også README (både den danske og den engelske) og `CHANGELOG.md`
- Scriptet har ingen afhængigheder og skal blive ved med at være sådan
